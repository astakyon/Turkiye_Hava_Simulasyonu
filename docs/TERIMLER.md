# Terim sözlüğü ve metin denetimi

Üretildi: `python3 tools/metinler.py` · oyuncunun gördüğü 3908 metin parçası tarandı (envanter verisi hariç). Testler `--check` ile çalıştırır; aykırı metin kalırsa yayın durur.

## Terim sözlüğü

| Kullanılmaz | Kullanılır | Not |
|---|---|---|
| `XP` | **TP** | Tecrübe puanının kısaltması her yerde TP. |
| `[Mm]isyon(lar)?` | **görev** | Oyunda "misyon" değil "görev". |
| `[Kk]anatçı` | **kanat adamı** | Yapay zekâ eşi "kanat adamı" (Kılıç 2). |
| `[Ss]kor` | **puan** | Oyun içi sayı "puan". |
| `[Ll]isans(lar\|lı\|ını\|ı)?` | **belge (ehliyet / sertifika)** | Genel ad "belge"; kara ve deniz için "ehliyet", hava için "sertifika". Ekranın adı "Ehliyet ve Sertifikalar". |
| `Taksiyi atla` | **Piste geç** | Dokunmatik düğme ve tuş aynı adı taşır: "Piste geç". |
| `[Aa]rtyakıcı` | **art yakıcı** | İki kelime. |
| `[İi]şaret fişeği` | **flare** | Oyunda "flare". |
| `[Ww]ingman` | **kanat adamı** | İngilizce ad kullanılmaz. |

**Diğer sabit terimler:** iniş takımı (dokunmatik düğmede kısaca TEKER) · art yakıcı · hava savunma (SAM) · İHA / SİHA (silahlı İHA) · Kartal Gözü (AWACS) · Kılıç 2 (kanat adamı) · Hilal Kanatlar / Mavi Kanatlar / Bozkurtlar (gruplar) · Hızlı Oyun · Kariyer · Harekât · Hızlı Savaş · Sorun giderme · Rehber.

## Yazım denetimi

Aranan sık hatalar: herşey → her şey, birşey → bir şey, hiç bir → hiçbir, yanlız → yalnız, malesef → maalesef, yalnış → yanlış, orjinal → orijinal, herkez → herkes, söför → şoför, pekçok → pek çok, şuanda|şuan → şu an, karşılaşdır → karşılaştır, deyil → değil, birtek → bir tek, herhangibir → herhangi bir, yanlızca → yalnızca, eksi̇k → eksik, katagori → kategori, süpriz → sürpriz, mütiş → müthiş.
